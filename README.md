Personal Portfolio

Hi, I'm Dhara Gadhavi. I'm a student who is curious about how technology works and enjoys turning ideas into things that people can actually use. I created this portfolio website as a place to introduce myself, share some of the projects I'm working on, and document my journey as I learn more about web development.

This project is more than just a personal information page for me. I wanted to build something from scratch that represents what I'm learning and gives me a place to experiment with design, interaction, and different web development ideas. I'm still learning, so this website will continue to change as I build more projects and improve my skills.

The portfolio starts with a simple introduction containing my name, a short description, and a little information about me. It also has an About section where I share details such as my age, class, city, interests, and the things I'm currently learning. Some of the information is still temporary and can be updated as the project develops.

The Work section is where I show the projects and ideas I have been working on. One of them is Journey to Space, which is a concept project based around booking space travel in the future. I created it as a way to explore web development and experiment with turning an idea into an actual website. Another project is a Study Planner, which is an idea for helping students decide what subject they should study first based on their weaknesses and their progress. It is still in progress, but I want to continue developing the idea and see where it can go.

I also wanted the portfolio to have some interaction instead of being a completely static page. The projects are displayed using expandable panels, so visitors can select a project and see its details while the other project closes. The name on the homepage also has a small letter-by-letter animation created with JavaScript. These are simple features, but they helped me understand how HTML, CSS, and JavaScript can work together to create a more interactive experience.

The contact section is another part of the project that I built myself. Visitors can copy my email address with a button, or they can enter their name and describe what they are building. When they click the send button, the website creates a mailto link and opens their email application with the message ready to send. I also added basic validation so the visitor is asked to enter their name and a message before the email is created.

I built the project using plain HTML, CSS, and JavaScript. HTML is responsible for the structure of the page, CSS controls the visual design and responsive layout, and JavaScript handles the interactive parts of the website. I used CSS variables to keep the colors organized and created the responsive layout with media queries so that the website can work on both larger screens and mobile devices. The project uses Bricolage Grotesque and Instrument Sans from Google Fonts to give the portfolio its visual style.

While building this project, I learned more about structuring a webpage with semantic HTML, creating layouts with CSS, using animations, manipulating elements with JavaScript, handling button events, working with the Clipboard API, creating email links, and making a page responsive. I also tried to think about accessibility by adding keyboard focus styles, ARIA attributes for interactive elements, and support for users who prefer reduced motion.

One of the things I like about this project is that it is simple enough for me to understand, but it still gives me plenty of opportunities to learn. I didn't want to make something that looked complicated just for the sake of looking complicated. Instead, I wanted to understand how each part works and build the features myself.

How to use it

There is no complicated setup required because this is a basic HTML, CSS, and JavaScript project. To run it, download or clone the repository and make sure index.html, style.css, and script.js are in the same folder. After that, open index.html in a web browser and the portfolio will start running. If you're using VS Code, you can also use an extension such as Live Server to make development easier and see changes immediately in the browser.
